# zotobs-io

🇬🇧 English · 🇧🇷 [Versão em português: LEIAME.md](LEIAME.md)

Zotero **annotations** ⇄ **Markdown/Obsidian**, in both directions, with a
**Zotero plugin** and a **command-line tool** (`zotobs`) that AI agents
(Claude Code, opencode, Gemini/Antigravity) can drive too.

- **Export** highlights, underlines, notes, free text, image areas and ink
  drawings from the Zotero reader to Markdown/JSON. Ink annotations come with
  the text they cover and a crop of the page with the drawing on top. Every
  annotation links back to the reader through `zotero://`.
- **Re-export without losing your writing:** text you add between annotations
  in the Obsidian note is kept when the note is refreshed.
- **Send it back:** comments/tags edited in Obsidian become edits to the
  Zotero annotations (`sync-md`), and annotations written in Obsidian or
  generated by an agent become **native Zotero annotations** on the right page.
- **Convert** Zotero annotations into annotations embedded in the PDF, and back.

> Why this is needed: the Zotero reader **does not write annotations into the
> PDF**; they live in the `zotero.sqlite` database, invisible to ordinary PDF
> tools. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

> **Language note:** the detailed documentation in `docs/` is currently in
> **Portuguese**. This README summarizes what you need to get started.

## How it differs from obsidian-zotero-integration

[obsidian-zotero-integration](https://github.com/obsidian-community/obsidian-zotero-integration)
(now maintained under `community-archive/`) is an **Obsidian plugin** widely
used to insert citations and bibliographies and to import notes and PDF
annotations from Zotero into Obsidian. According to its README it requires
Better BibTeX. It is the right tool if you want to **search and cite
references from inside Obsidian**.

zotobs-io solves a different problem, and the two complement each other:

|                                  | obsidian-zotero-integration                                                   | zotobs-io                                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Runs in                          | Obsidian                                                                      | **Zotero** (plugin) and the **terminal** (CLI/agents); Obsidian only needs to open `.md` files |
| Focus                            | citations, bibliographies, reading notes, importing annotations into Obsidian | the **life cycle of annotations** between Zotero and Markdown                                  |
| Direction                        | Zotero → Obsidian (per the project's README)                                  | Zotero → Markdown **and** Markdown → Zotero                                                    |
| Writes to Zotero                 | not described                                                                 | yes: creates native annotations, edits comments/tags of existing ones                          |
| Re-importing over an edited note | —                                                                             | **merge**: refreshes the blocks, keeps what you wrote between them                             |
| Ink and image areas              | —                                                                             | page crop with the drawing on top, plus the text under the drawing                             |
| AI automation                    | —                                                                             | deterministic CLI + agent *skill*                                                              |
| Requires Better BibTeX           | yes (per the project's README)                                                | no                                                                                             |
| Works without Obsidian           | no                                                                            | yes (any Markdown editor)                                                                      |

In short: use obsidian-zotero-integration to **cite and import references**;
use zotobs-io when **annotations are the working material** — to review them,
comment on them in Obsidian, send them back to Zotero or hand them to an
agent. Nothing stops you from using both.

## Quick start (macOS/Linux)

The step-by-step guide for beginners — including how to install `uv` — is
[docs/INSTALL.md](docs/INSTALL.md) (Portuguese).

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh     # installs `uv` (open a new terminal afterwards)
git clone https://github.com/zepadovani/zotobs-io.git ~/repositorios/zotobs-io
cd ~/repositorios/zotobs-io
./install.sh --all                                   # `zotobs` command + agent skill
zotobs info "/path/to/paper.pdf"                     # does Zotero recognise this PDF?
zotobs extract "/path/to/paper.pdf" -o notes.md --imagens notes_img
```

**What is `uv`?** A free tool that runs Python scripts and installs what they
need (here, the `pymupdf` PDF library) in isolation, without touching your
system Python. **Windows:** `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`,
then `install.ps1` instead of `install.sh`.

Then install the plugin (the `.xpi` file) in Zotero: *Tools → Plugins → gear →
Install Plugin From File…*, and pick the export folder in
*Settings → zotobs-io*. Right-click an item (or use the **zotobs** /
**zotobs…** buttons in the PDF reader) to export its annotations.

## How an annotation reaches Zotero

```
 Markdown note (Obsidian) ─┐
 JSON (agent)             ─┴─►  zotobs add  ──►  1. zotobs-bridge plugin (local, no network, no key)
                                                 2. Zotero Web API       (needs key and network)
                                                 3. JS snippet           (paste into Run JavaScript)
                                                 4. --destino pdf        (embedded in the file)
```

Running the same file again **does not duplicate** anything: each annotation
has a deterministic key.
