# Exemplo de nota do Obsidian (sintaxe de entrada do `zotobs add`)

Sob um título de página, cada linha com `::` vira uma anotação.

## p. 3
> trecho literal que existe na página 3 :: por que esse trecho importa {verde}
_> outro trecho literal :: sublinhado com comentário {azul}
- :: comentário geral sobre esta página {laranja}

## pl. iv
> texto da página impressa iv :: página escolhida pelo rótulo impresso

Linhas sem dois-pontos duplos (como esta) são ignoradas.
